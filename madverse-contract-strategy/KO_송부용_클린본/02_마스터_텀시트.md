# 마스터 텀시트

프로젝트: MAD POP / 사공이호 1단계  
일자: 2026년 5월 27일  
문서 상태: 비밀유지, 독점성, 우회금지, 준거법, 분쟁해결, 비용에 관하여 확정 계약서에서 명시적으로 합의되는 경우를 제외하고는 구속력 없는 논의용 초안입니다.

## 1. 거래 구조

본 프로젝트는 하나의 기본 상업 조건 아래 두 개의 연동 계약으로 구성됩니다.

```text
계약 A:
크리에이티브 디렉터 / 총괄 프로듀서 / 신규 IP 개발 계약

계약 B:
사공이호 제한적 IP 사용권 계약
```

계약 A와 계약 B는 서로 연결된 프로젝트 문서입니다. 서면으로 달리 합의하지 않는 한, 두 계약이 모두 체결되어야 전체 프로젝트 문서가 완전히 효력을 가집니다.

## 2. 당사자

| 계약 | 당사자 | 역할 |
|---|---|---|
| 계약 A | 중국 측 및 KHS 크리에이티브 회사 또는 김형석 | 창작 방향 설정, 총괄 프로듀싱, 음악감독, 신규 IP 개발 |
| 계약 B | 중국 측 및 노느니 | 사공이호 IP의 제한적 사용권, 선급/최소보장금 및 매출연동 러닝 로열티 |
| 지분 / 옵션 사이드레터 | 중국 측 및 KHS 크리에이티브 회사 또는 지정 지분보유 법인 | 30% 전략 지분 또는 30% 지분 옵션 |

김형석은 계약 A의 핵심 창작자로 명시됩니다.

노느니는 계약 B의 사공이호 IP 권리자 또는 사용권을 부여할 권한이 있는 주체로 명시됩니다.

## 3. 상업 조건

| 항목 | 제안 조건 |
|---|---|
| 전체 초기 대가 | 50억 원 이상 |
| 계약 A 대가 | 45억 원~47억 원 |
| 계약 B 대가 | 선급/최소보장금 3억 원~5억 원 + 순매출액 기준 매출연동 러닝 로열티 |
| 지분 / 옵션 | 노느니가 아니라 KHS 크리에이티브 회사 또는 지정 지분보유 법인에 30% 지분 또는 30% 지분 옵션 부여 |
| 지급 성격 | 프로젝트 투자금, 주주대여금, 운영비 또는 회수 대상 비용과 분리되는 환급 불가의 크리에이티브 피, 라이선스 피 및 러닝 로열티 |

계약 A 지급 일정:

| 단계 | 지급 |
|---|---:|
| 서명 | 40% |
| 창작 방향 패키지 제공 | 30% |
| 중국 현지화 / 신규 IP 개발 단계 | 20% |
| 런칭 준비 검토 | 10% |

계약 B 선급/최소보장금 지급 일정:

| 단계 | 지급 |
|---|---:|
| 서명 | 70% |
| 승인된 IP 자료 묶음 제공 | 30% |

계약 B 매출연동 러닝 로열티:

| 대상 | 기준 |
|---|---:|
| 사용 대상 IP가 직접 사용된 콘텐츠, 서비스, 프로젝트 매출 | 순매출액의 3% |
| 굿즈, 캐릭터 상품, 상품화 매출 | 순매출액의 5% |
| 재라이선스 또는 서브라이선스 수령액 | 순수령액의 25% |

`순매출액`은 총수령액에서 부가세, 환불, 승인된 결제수수료만 공제한 금액입니다. 마케팅비, 인건비, 내부 운영비, 관계사 수수료, 플랫폼 개발비, 상장비용은 공제하지 않습니다.

## 4. 계약 A 범위

계약 A는 다음을 포함합니다.

1. 크리에이티브 디렉터 역할.
2. 총괄 프로듀서 역할.
3. 신규 버추얼 아티스트 및 음악 IP 개발.
4. 음악감독.
5. 중국 현지화 창작 패키지.
6. 핵심 창작 자료 검토.
7. 예정된 창작 회의에 대한 합리적 참여.

계약 A는 다음을 포함하지 않습니다.

1. 사공이호 IP 소유권 보증.
2. 중국 시장 매출 보증.
3. 투자유치, 상장, 규제 승인 또는 상업적 성공 보증.
4. 제3자 아티스트 참여 보증.
5. 무제한 상장 실사 또는 감사 협조.
6. 별도 서면 합의가 없는 김형석의 개인보증.

## 5. 계약 B 사용권 범위

| 항목 | 제안 범위 |
|---|---|
| 사용 대상 IP | 사공이호 캐릭터, 승인된 시각 정체성, 승인된 세계관 자료, 승인된 참고 자료 |
| 지역 | 서면 승인 없는 한 중국 본토 한정 |
| 프로젝트 | MAD POP 1단계 한정 |
| 기간 | 최초 3년 + 2년 갱신 옵션 |
| 독점성 | 승인된 지역, 기간, 프로젝트 안에서만 제한적 독점 |
| 제3자 사용 허락 | 사전 서면 승인 없이는 불가 |
| AI 학습 | 별도 서면 승인 없이는 불가 |
| 2차 창작물 | 사전 승인 필요 |
| 종료 후 사용 | 불가 |

## 6. 우회금지

중국 측은 KHS 크리에이티브 회사, 김형석 또는 노느니를 직접 또는 간접적으로 우회하여 아래 항목을 취득, 개발, 등록, 상업화, 재라이선스, 금융화, 토큰화 또는 활용할 수 없습니다.

1. 사공이호;
2. 혼동 가능성이 있는 유사 캐릭터, 명칭, 표장, 도메인, 계정 또는 디지털 아바타;
3. 사공이호에 기반한 2차 창작물;
4. 프로젝트에서 생성된 신규 IP 콘셉트, 음악 콘셉트, 캐릭터 콘셉트, 세계관 자료 또는 창작 자료.

## 7. 책임

각 당사자는 자기 계약과 자기 범위에 대해서만 책임을 집니다.

KHS 크리에이티브 회사는 다음에 대해 책임을 지지 않습니다.

1. 사공이호 소유권 보증;
2. 규제 실패;
3. 투자유치 실패;
4. 상장 지연;
5. 시장 실패;
6. 사업 중단;
7. 간접손해;
8. 기대수익;
9. 중국 측 또는 그 계열회사로 인해 발생한 손실.

노느니는 다음에 대해 책임을 지지 않습니다.

1. 크리에이티브 디렉션 성과;
2. 신규 IP 개발 성과;
3. 시장 성과;
4. 상장, 투자유치, 규제 또는 운영 결과.

총 책임은 고의 또는 중과실로 인한 직접손해로 제한되며, 해당 계약 당사자가 실제 수령한 금액을 초과하지 않습니다.

## 8. 비용 및 회수 방지

계약 A와 계약 B에 따라 지급된 대가는 다음으로 취급되지 않습니다.

1. 주주대여금;
2. 프로젝트 선급금;
3. 환급 대상 비용;
4. 회수 대상 운영비;
5. 상장 비용;
6. 출자금 반환 의무.

중국 측은 프로젝트 손실, 투자유치 지연, 상장 지연, 규제 지연, 시장 실패 또는 운영비 초과를 이유로 계약 A 대가 또는 계약 B 대가의 환급, 변제, 상계 또는 회수를 요구할 수 없습니다.

## 9. 지분 / 옵션

중국 측은 장기 성공 인센티브로 KHS 크리에이티브 회사 또는 지정 지분보유 법인에 프로젝트 회사 또는 지정 보유회사 지분 30% 또는 그에 상응하는 30% 지분 옵션을 부여합니다.

해당 지분 또는 옵션은 노느니에 부여되지 않습니다.

해당 지분 또는 옵션은 한국 공직, 이해충돌, 세무, 외환, 규제 또는 법규 준수 요건이 발생하는 경우 매각, 이전, 포기, 백지신탁, 현금정산 또는 기타 필요한 처리가 가능하도록 구성되어야 합니다.
